# 🎙️ Voice-Based Email System

A web-based email application that allows users to send and read emails using voice commands. It is designed to make email communication easier for visually challenged users.

## 🚀 Features

* 🎤 Voice commands
* 📧 Send emails
* 📥 Check inbox
* 📖 Read latest email
* 🔐 Gmail login
* 🔢 OTP generation
* 🔊 Text-to-Speech
* 🌐 Multiple language support

## 🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* Speech Recognition
* Text-to-Speech
* Gmail SMTP
* Gmail IMAP

## 🔄 How It Works

```text
User speaks
    ↓
Speech Recognition
    ↓
JavaScript
    ↓
Flask Backend
    ↓
Gmail SMTP / IMAP
    ↓
Response
    ↓
Text-to-Speech
```

## 📧 Email Operations

### Send Email

The application uses **SMTP** to send emails through Gmail.

### Read Email

The application uses **IMAP** to retrieve emails from Gmail.

## ⚙️ How to Run

### 1. Clone the project

```bash
git clone https://github.com/sharumathi755/voice_based_email.git
```

### 2. Install Flask

```bash
pip install flask
```

### 3. Run the application

```bash
python app.py
```

### 4. Open in browser

```text
http://127.0.0.1:5000
```
